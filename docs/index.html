Core Capabilities

  • 100% Privacy Focused No registration required, zero internet analytics frameworks, and no ads. All vehicle data is stored fully locally on your device in a Room-managed SQLite database.
  • Persistent Local Ledger Saves 1-minute vehicle heartbeats (RPM, voltage, thermal limits, speed) while the engine is running to build a comprehensive historical record of driving sessions.
  • Gemini AI Assistant Integration Queries local databases in natural language. The assistant converts user questions (e.g., "What was my peak RPM yesterday?") into local SQL queries, retrieves the answer securely, and narrates diagnostics.
  • Multi-Factor Hardware Calibration Allows adjusting OBD telemetry values to correct vehicle sensor irregularities, such as custom fuel gauge scaling factors for Renault/Nissan CMF-A+ platforms.
  • Modern Graph Visualization Generates clean, scaling Compose Canvas trend graphs indicating precise Y-axis bounds and relative X-axis timestamps without text or line overlap.
  • Android Auto Integration Extends core metrics securely to your vehicle's dashboard display using standard Android Auto templates.
